The constraints

What made this interesting.

The usual options were off the table, which shaped what a good answer looked like.

$

No budget

No software procurement, no contractors. The fix had to come from within the team, using tools already on hand.

⊘

No cloud, no network

No syncing, no analytics, no remote fonts. The tool needed to work entirely offline — and stay working when the knowledge base went down.

⌘

No install rights

CSR workstations were locked down. Whatever I built had to run from a regular file in the default browser.

⎋

No saved data

Privacy review meant no storage of any kind — no localStorage, no filesystem, not even autofill. Each note had to exist for one call and disappear.

What went in

Four scattered tools, one panel.

Each feature replaced something CSRs were already doing — but on the desktop, in a different app, with no shared format.

Notes

Structured note-taking

One panel with every required field — caller, account, authorization, reason, resolution. The generated output is identical every time, which is what made QA scoring objective.

Calendar

90-days-ago, computed

A common reference point for disputes and refunds. The date is calculated on page load and a one-click calendar opens to that month, highlighted.

Calculator

Inline math with history

Standard four-function math plus a running log of every calculation. Keyboard input works when the panel is focused, so a CSR can stay on keys.

Reference

Tabbed reference, fully offline

Express Lanes exit codes for every Bay Area corridor, in two columns by direction. Loads in a second, and keeps working when the knowledge base doesn't.

The unplanned win
The format also gave QA a consistent template to score CSRs against — something the team had been working around for years.

Because every generated note shares the same structure, reviewers can compare like with like, instead of parsing whatever each CSR happened to type that day.

How it works

Privacy built into the structure.

The whole workspace is one HTML file with no dependencies and no build step. Fields are rebuilt on every page load, autofill is disabled at the attribute level, and there's no persistence layer to begin with.

Because nothing is stored, there's nothing to leak. And because nothing is fetched, nothing breaks when the network does.

// Disable autofill and persistence on every input. document.querySelectorAll('input, textarea') .forEach(el => { el.setAttribute('autocomplete', 'off'); el.setAttribute('data-lpignore', 'true'); el.setAttribute('spellcheck', 'false'); }); // Block network calls at the primitive level. if (typeof fetch !== 'undefined') { window.fetch = () => { throw new Error('Network disabled'); }; }
